Launch in your Windows 10 file PUBLISH_WIN10.cmd . It will download libruaries from Microsoft and build EXE of launcher in folder publish\win10-x64\ValkyrieRevival.exe

Start it, set up settings (path to game and etc.). 

Register as pilot on https://playevevalkyrie.com/ or in launcher, and enjoy! :)

You can play as in VR mode (tested on Oculus2) as and in Desktop 2D mode. 
But I highly recommend to play in VR for this game! ;)
